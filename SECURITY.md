# Security policy

Report security vulnerabilities through the [repository's Security page](https://github.com/tkarakai/the-way-i-ai/security). Select **Report a vulnerability** to submit a private report to the maintainer. A GitHub account and sign-in are required.

Include the affected URL, site edition, reproduction steps and potential impact. Do not post credentials, personal data, or working exploits in a public issue.

The published site is static. Browser behavior, authored Markdown and SVG, the generator, dependencies and the GitHub Actions deployment pipeline are in scope. Source changes should include a reproducible example and an appropriate regression check. Only the latest published edition is maintained.

The site publishes the contact and this policy at `/.well-known/security.txt`, a standard discovery location for security researchers. Its expiry is regenerated with each build and is separate from article publication dates.
